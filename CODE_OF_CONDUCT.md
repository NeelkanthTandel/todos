# Code of conduct

Todos follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work. Harassment, insults and personal attacks aren't tolerated in issues, pull requests, discussions or anywhere else the project is represented.

To report unacceptable behaviour, contact the maintainer privately through GitHub (for example, a private security advisory on this repository if you'd rather not post publicly). Reports are kept confidential. Maintainers may remove comments, close threads or block participants who break these rules.
